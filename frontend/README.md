# Frontend

Next.js (App Router) + Tailwind demo UI for the Classroom Voice Analytics MVP. The
[root README](../README.md) covers setup, the analysis pipeline, metrics, and hosting.

```bash
npm run dev            # local dev against the FastAPI backend on :8000
npm run build          # production build — static data mode, reads public/results/
npm run sync-results   # copy backend/data/results into public/results/
```
